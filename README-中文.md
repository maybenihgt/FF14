# Mahjong AI Assistant 1.0

面向 Dalamud API 15 / .NET 10 的轻量麻将手牌分析插件项目。

## 当前功能
- 游戏内 Dalamud 窗口，命令 `/maia` 打开。
- 本机账号标签：MAIN_A、MAIN_B、ALT_C、ALT_D。
- 手动输入 13/14 张闭门手牌。
- 标准型、七对子、国士无双向听数。
- 13 张手牌有效牌计算。
- 14 张手牌弃牌比较。
- 不需要外部模型、Python、授权服务器或环境包。

## 输入格式
`123m 456p 789s 1112z`

- m：万子；p：筒子；s：索子；z：字牌（东南西北白发中依次为 1–7）。
- 只接受 13 或 14 张；每种牌最多四张。

## 重要限制
- 这是闭门日本立直麻将的基础算法，不代表已完整适配 FF14 多玛麻将特殊规则。
- 当前不自动识别游戏窗口，不读取游戏进程内存，不读取对手隐藏信息。
- 理论有效牌数只按输入手牌扣除，未考虑牌河、副露、宝牌及场况。
- 不提供自动出牌、多账号协同操纵牌局或保证指定账号获胜的功能。

## 构建
项目目标为 Dalamud API 15 / .NET 10，使用 `Dalamud.NET.Sdk/15.0.0`。

本仓库包含 GitHub Actions 工作流：推送到 `main` 或在 Actions 手动运行 `Build Mahjong AI Assistant` 后，下载构建 Artifact。Artifact 只有在工作流真实成功后才可作为插件 DLL 使用。

## 安装
成功构建后，将生成的 DLL 添加到 Dalamud 的「设置 → 插件 → 本地插件」中。实际发布目录结构以构建输出为准；不要只复制 DLL 而遗漏依赖清单。
