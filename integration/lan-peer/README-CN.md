# UU 云联机四客户端名单测试版

此功能用于将加入同一个 UU 云联机虚拟局域网、并启用了插件节点发现的客户端列入同一份四客户端名单。

## 使用方法

1. 在最多四台电脑上手动加入同一个 UU 云联机房间。
2. 在插件主窗口切换到 **多人模式**。
3. 每台电脑的账号类型默认是 **小号**；只有主动选择 **大号** 才会广播为大号。
4. 每台电脑开启 **加入四人桌 / 启用节点发现**。
5. 在 Windows Defender 防火墙的“专用网络”配置文件中允许 UDP 入站端口 **47721**。
6. 等待几秒钟，名单会显示本机和同一可见 IPv4 子网内发现的其他插件实例，最多显示四个客户端。

不再需要插件自己的共享房间码。UU 云联机房间由用户手动加入；插件通过 IPv4 UDP 广播发现同一可见子网内的插件实例。

## 大号 / 小号身份

- 默认身份是 **小号**。
- 只有用户主动点击 **大号**，该客户端才会以大号身份广播。
- 不再使用 MAIN_A、MAIN_B、ALT_C、ALT_D 等账号标签。
- 身份仅用于本地界面和在线名单标记，不是账号凭据。

## 四人名单与实际麻将对局的区别

当前多人页提供的是四客户端在线名单，不是独立的麻将游戏服务器或实时牌局同步器。真正的麻将对局仍在 FF14 游戏内开始和运行。

此版本不会跨客户端同步手牌、牌河、分数、对手信息、游戏状态或游戏动作。旧的 backend/team_room.py 是独立的 2v2 私人沙盒/积分测试原型，只接收手动提交的 JSON 快照和赛后积分，不是本插件的实时四人牌局功能。

## 交换的数据与边界

广播内容仅包括：
- 随机插件实例 ID（插件重载后会变化）
- 本地账号类型：大号或小号
- 插件版本
- 时间戳

该协议不包含 HMAC 共享密钥，也不提供密码学身份认证。它只用于同一局域网内的在线状态展示；同一可见子网内其他启用节点发现的插件实例也可能出现。因此不要把在线名单当作 UU 房间成员的权威名单。

## 故障排查

- 确认所有电脑确实加入了同一个 UU 云联机房间。
- 确认每台电脑都启用了节点发现。
- 确认 Windows 防火墙允许专用网络 UDP 47721 入站。
- 如果两台电脑可以互相 ping，但名单仍为空，可能是 UU 虚拟网卡没有转发 IPv4 广播；届时需要增加单播发现回退方案。
- 节点超过 8 秒没有心跳会从名单中消失。
- 节点发现默认关闭，不会改变单人模式中的 Off / Hints / Auto-play 设置。
