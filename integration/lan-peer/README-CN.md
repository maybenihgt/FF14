# UU 云联机四客户端全手牌私人训练模式（测试版）

## 设计前提

此模式只用于你们四名参与者都知情并明确同意的私人 UU 云联机牌桌。四人可以共享各自客户端本机读取到的暗手牌，构成全信息训练桌。不要在公开匹配、排位或有未同意参与者的牌局中启用。

## 使用方法

1. 四台电脑手动加入同一个 UU 云联机房间。
2. 四台电脑安装同一个版本的插件，并在多人模式开启「加入四人桌 / 启用节点发现」。
3. 每台电脑选择本机身份：默认小号，可主动切换大号。
4. 四名参与者分别勾选「我同意向这张私人四人桌共享本机手牌」。
5. 只有恰好四个插件客户端都在线且四台都同意后，才会开始发送 UDP 47723 手牌数据。
6. 每台电脑都应看到「明确同意共享手牌：4/4」，并逐步收到其他三人的手牌。

## 同步范围

- UDP 47721：在线节点发现、账号类型及各客户端是否同意共享手牌。
- UDP 47722：可选公开牌局状态同步。
- UDP 47723：四人全部同意后，传输每个客户端本机读取的手牌、赤牌标记和座风。

每个客户端只发送自己本机 `StateSnapshot` 中读取到的 13/14 张手牌。接收端会校验发送者是否在当前四人名单中、是否广播了同意状态、手牌张数、牌值范围、每种牌不超过四张、赤牌标记和当前牌局指纹。只有牌局公开状态指纹一致时才显示远端手牌。

## 同意和退出规则

- 默认不共享；插件配置 `ConcealedHandShareConsent` 默认 false。
- 四台机器必须各自主动勾选同意，不能由房主替其他人勾选。
- 必须恰好四个插件实例；多于或少于四个时不发送手牌。
- 任意一台取消勾选、离开桌子或心跳超时，其他客户端立即停止接收/显示共享手牌并清空缓存。
- 手牌共享仅使用私有 UU 虚拟局域网内的 IPv4 UDP 广播，不经过公网服务器。

## 安全提醒

此版本的 UDP 广播没有加密或密码学身份认证。同一可见子网内的其他设备可能监听网络流量。因此只应在你完全信任、仅供四名参与者使用的私有 UU 网络中打开手牌共享。不要在公共网络或有其他不受信任成员的虚拟局域网中使用。

## 当前实现边界

本阶段实现的是四人明确同意后的手牌交换与显示。四家手牌仍各自来自本机游戏界面读取；远端手牌不会被伪造或推断。

**统一 AI 的全信息分析、按大号优先级计算并向各客户端分发建议，尚未接入本阶段的手牌传输模块。** 需要先确认四端手牌同步与牌局指纹在实机测试中稳定一致，再接入统一策略协调器。插件不会在此阶段自动向游戏发送操作。

## 网络排查

- Windows 防火墙允许专用网络 UDP 47721、47722、47723 入站。
- 四台电脑必须都运行包含 `doman-mahjong-peer-v4` 和 `doman-consented-hand-v1` 的同一版本。
- 如果名单是 4/4、同意也是 4/4，但手牌仍未显示，请先检查本机是否提示「本机公共状态尚未通过一致性校验」；未通过校验的快照不会发送。
- 如果显示牌局指纹不匹配，检查四台是否确实在同一张游戏桌且公开状态都已更新。
